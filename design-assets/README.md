# Design Assets — RentA

Adaugă în acest folder fișierele SVG de logo pe măsură ce le finalizezi:
- `logo-primary.svg` (lockup principal)
- `logo-dark.svg`
- `logo-icon.svg` (icon-only)
- `logo-wordmark.svg` (wordmark-only)
- `logo-mono.svg`

Până la adăugarea fișierelor SVG finale, componenta `BrandLogo` din `components/ui/BrandLogo.tsx` folosește un wordmark tipografic minimalist în `Archivo Expanded` + badge tehnic `JetBrains Mono`, astfel încât înlocuirea cu SVG-ul final să se facă într-un singur fișier.
